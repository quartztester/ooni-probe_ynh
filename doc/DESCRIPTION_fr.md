OONI Probe, de l'Open Observatory of Network Interference (communauté Tor
Project), mesure l'interférence réseau : quels sites sont bloqués depuis une
connection donnée. Les mesures publiées forment OONI Explorer.

Ce paquet exécute OONI Probe comme service planifié : deux campagnes par jour
sur un ensemble borné d'URL, puis publication anonymisée des résultats. Aucune
port ouverte, aucune interface web.
