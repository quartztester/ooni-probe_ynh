# OONI Probe pour YunoHost

OONI Probe mesure la censure et les interférences réseau (tests de connectivité web uniquement) et publie des mesures anonymes sur ooni.org. Ce paquet exécute le binaire officiel via un minuteur systemd — pas d'interface web.

**Version livrée :** 3.30.0

## Caractéristiques

- Binaire statique officiel, somme de contrôle vérifiée
- Tests de connectivité web uniquement (pas de tests de débit)
- Minuteur systemd configurable (intervalle, limite d'URL)
- Résultats publiés anonymement sur explorer.ooni.org
